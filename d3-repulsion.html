Assignment Overview

This page extends the D3 animation example built in class (Lab T3). I chose Option 3: every click adds a new circle to the canvas, and shapes are repelled away from the mouse pointer in real-time using a physics-based force simulation built with D3 v7.

Implementation Notes

Repulsion model: Each frame, the distance between the mouse and every circle is computed. If within the repulsion radius (120px), a force vector pointing away from the mouse is added to the circle's velocity. The force uses a squared falloff — (1 - dist/radius)^2 — so it feels smooth and organic rather than abrupt.

Physics: Velocity is damped by 0.80x each tick (~60fps) so circles gradually slow down and settle after being pushed. Bouncing off walls reverses the relevant velocity component with a small energy loss (0.5x) to prevent infinite oscillation.

D3 role: D3 handles the spawn animation (pop-in with overshoot via d3.easeBackOut) and SVG element lifecycle. Per-frame position updates use a manual setInterval loop that directly sets cx/cy attributes — showing where D3's declarative model hands off to imperative animation logic.
